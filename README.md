# Физика — демо-сайт

Статический сайт для учителя физики: 7, 8 и 9 классы, по три темы на класс.
На каждой странице размечены места под видеоурок, задачи, конспект, тест
и дополнительные материалы. Сейчас это заглушки — учитель пришлёт файлы позже.

## Структура

```
physics-site/
├── index.html          главная: выбор класса, об учителе
├── grade-7.html        7 класс
├── grade-8.html        8 класс
├── grade-9.html        9 класс
├── development.html    «сайт в разработке»
├── 404.html            страница «не найдено»
├── assets/
│   ├── style.css       все стили
│   └── files/          сюда складываются PDF и другие материалы
├── robots.txt          запрет индексации для поисковиков
├── .nojekyll           служебный файл GitHub Pages
└── README.md
```

## Посмотреть локально

Откройте `index.html` двойным щелчком — сайт работает без сервера и интернета.
Шрифты системные, внешних зависимостей нет.

## Выложить на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com).
2. **New repository** → имя, например `physics-site` → **Public** → **Create repository**.
   На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
3. **Add file → Upload files** → перетащите содержимое папки `physics-site`
   (`index.html`, `grade-*.html`, `404.html`, папку `assets`, `robots.txt`).
   Файл `.nojekyll` можно не загружать — он не обязателен.
4. **Commit changes**.
5. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
6. Через 1–2 минуты сайт будет здесь: `https://ВАШ-ЛОГИН.github.io/physics-site/`.

Ссылку никуда не публикуйте — в этом и смысл схемы.

## Важно про приватность

- На каждой странице стоит `noindex, nofollow` — поисковики её не покажут.
  `robots.txt` для проекта на GitHub Pages лежит не в корне домена, поэтому
  основная защита — именно мета-тег.
- Но **ссылка работает у всех, кому вы её передали**. Пароля нет.
- **Репозиторий публичный**, значит файлы видны и на github.com. Для теста это
  нормально. Для настоящих авторских материалов лучше платный GitHub
  (приватный репозиторий + Pages) или обычный хостинг.

## Как заменить заглушки

### Названия тем и описания

В `grade-7.html` (и так же в 8 и 9) найдите:

```html
<h2 id="topic-1-title">Строение вещества</h2>
<p>Молекулы и атомы, диффузия, три агрегатных состояния вещества.</p>
```

и замените текст. Подписи в меню тем выше тоже стоит поправить:

```html
<a href="#topic-1">01 · Строение вещества</a>
```

Названия тем сейчас примерные, по школьной программе — поменяйте под свою.

### Видео

Найдите блок с превью:

```html
<div class="video-poster" role="img" aria-label="...">
  ...
</div>
```

и замените его целиком на вставку с Rutube, VK Видео или YouTube:

```html
<div class="video-frame">
  <iframe src="ССЫЛКА_НА_ВИДЕО" title="Видеоурок" allowfullscreen></iframe>
</div>
```

Класс `.video-frame` уже есть в стилях — рамка и пропорции 16:9 подставятся сами.

### Задачи и конспект

1. Положите PDF в `assets/files/`.
2. В карточке замените заглушку

   ```html
   <span class="pill">PDF · скоро</span>
   ```

   на ссылку

   ```html
   <a class="pill pill-link" href="assets/files/7-tema-1-konspekt.pdf">Открыть PDF</a>
   ```

### Тест

Кнопка «Начать тест» сейчас отключена. Когда тест будет готов, замените

```html
<button class="btn" type="button" disabled>Начать тест</button>
```

на ссылку на Яндекс Формы или Google Формы:

```html
<a class="btn" href="ССЫЛКА_НА_ТЕСТ">Начать тест</a>
```

### Имя учителя и контакты

На главной в блоке «Об учителе» замените текст с классом `tbd`
на настоящее описание, добавьте фото и почту.

## Ограничения GitHub Pages

- только статика: нельзя пароль, загрузку файлов через сайт, базу данных;
- сайт до 1 ГБ, трафик около 100 ГБ в месяц;
- видео файлами лучше не заливать — используйте видеохостинг.

## Что можно добавить дальше

- имя, фото и контакты учителя;
- редактор поверх GitHub (Decap CMS), чтобы учительница правила страницы
  без знания HTML;
- свой домен вместо адреса `github.io`;
- страницу «Домашние задания» и расписание.
