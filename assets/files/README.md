# Материалы

Сюда учитель кладёт файлы: конспекты, задачи, презентации, таблицы.

## Как назвать файлы

Латинскими буквами, без пробелов — так ссылки не ломаются:

- `7-tema-1-konspekt.pdf`
- `7-tema-1-zadachi.pdf`
- `8-tema-2-prezentaciya.pdf`

## Как подключить файл к сайту

1. Скопируйте PDF в эту папку и загрузите на GitHub вместе с сайтом.
2. Откройте нужную страницу класса, например `grade-7.html`.
3. Найдите карточку «Задачи» или «Конспект» и замените заглушку

   ```html
   <span class="pill">PDF · скоро</span>
   ```

   на ссылку

   ```html
   <a class="pill pill-link" href="assets/files/7-tema-1-zadachi.pdf">Открыть PDF</a>
   ```

Файл откроется в новой вкладке браузера. Скачать его всё равно можно —
полностью запретить скачивание у статического сайта не получится.
